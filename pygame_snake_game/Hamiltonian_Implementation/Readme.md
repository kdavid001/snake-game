# Hamiltonian Cycle and Prim’s Algorithm

This folder contains all the code for solving the **Hamiltonian Cycle** problem, including implementations of **Breadth-First Search (BFS)** and **Prim’s Algorithm**.

## Files

- `Ham_cycle.py` – Contains the implementation for finding Hamiltonian Cycles in a graph using BFS.
- `prims_algorithm.py` – Contains the implementation of Prim’s algorithm for finding the Minimum Spanning Tree (MST) of a graph.

## Overview

- **BFS (Breadth-First Search)**: Explores nodes level by level and is used here to systematically traverse the graph for Hamiltonian cycles.
- **Prim’s Algorithm**: Builds the MST of a graph by iteratively adding the smallest edge that connects a new vertex.

## How to Run

1. Ensure you have Python 3.x installed.
2. Run the desired script from the command line:
   ```bash
   python Ham_cycle.py
   python prims_algorithm.py
